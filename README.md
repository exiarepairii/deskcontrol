# DeskControl

> **Язык:** Русский · [English](README.en.md) · [简体中文](README.zh.md)

DeskControl превращает ваш телефон в тачпад и гироскопную мышь для отдельного приложения, запущенного на проводном внешнем дисплее. Поддерживает Android 11+ и ориентирован на Android 16 (API 36). Для отображения курсора и передачи действий ввода используется служба специальных возможностей (AccessibilityService).

## Основные возможности

- Запуск любого установленного приложения на проводном внешнем дисплее.
- Управление внешним приложением с помощью тачпада на телефоне (перемещение, клики, перетаскивание, прокрутка).
- Управление гироскопом (Motion Mouse) с быстрой калибровкой и виброоткликом.
- Наложение курсора для каждого дисплея с автоскрытием и гибкой настройкой.
- Автоматическое выключение экрана телефона (blackout) для предотвращения случайных касаний.
- Перенаправление кнопки «Назад» на внешний экран.
- Опциональный режим скрытия интерфейса тачпада (полностью чёрный экран для опытных пользователей).
- Корректное завершение работы при отключении внешнего дисплея.

## Требования

- Android 11+ (minSdk 30).
- Android 16 target SDK (API 36).
- Проводной внешний дисплей (Type-C / DisplayPort Alt Mode).
- Включенная служба специальных возможностей (необходима для курсора и передачи ввода).

## Быстрый старт

1. Подключите проводной внешний дисплей к телефону.
2. Откройте приложение, ознакомьтесь с условиями и включите службу спец. возможностей DeskControl.
3. Выберите приложение для запуска на внешнем дисплее.
4. Откройте Тачпад или Гироскопную мышь и управляйте приложением.

## Использование тачпада

- Перемещение: проведите одним пальцем по области тачпада.
- Клик: коснитесь один раз в области тачпада.
- Перетаскивание: коснитесь, удерживайте и ведите палец (вибрация подтвердит начало).
- Прокрутка: проведите двумя пальцами вверх или вниз.
- Автозатемнение: через 10 секунд в области тачпада экран затемняется. Яркость восстанавливается при касании вне области или выходе.
- Назад: пока область тачпада активна, нажатие/жест «Назад» передается внешнему приложению.
- Центрирование курсора: зажмите клавишу Громкость Вниз.
- Выключение экрана телефона: зажмите клавишу Громкость Вверх (дисплей продолжит работать).
- Выход: нажмите стрелку «Назад» в верхнем левом углу или коснитесь за пределами тачпада и выполните системный жест «Назад».

## Сборка проекта

Поддерживаются две версии (flavor) из одного исходного кода:

- `play`: пакет `com.suspace.deskcontrol`, Google Play Billing, значки поддержки, без Shizuku.
- `direct`: пакет `com.deskcontrol`, опциональная активация через Shizuku, без биллинга Play и платных значков.

```bash
./gradlew assemblePlayDebug
./gradlew assembleDirectDebug
```

Установка APK:

```bash
adb install -r app/build/outputs/apk/play/debug/app-play-debug.apk
adb install -r app/build/outputs/apk/direct/debug/app-direct-debug.apk
```

## Настройки

- Размер курсора, прозрачность, цвет и задержка автоскрытия.
- Чувствительность тачпада, ускорение, порог дрожания, сглаживание и шаг прокрутки.
- Режим полного скрытия интерфейса тачпада (чёрный экран).
- Настройки гироскопа: углы охвата, сглаживание, интервалы и виброотклик.
- Не выключать экран во время использования контроллера.
- Автозатемнение тачпада через 10 секунд.
- Выбор языка интерфейса (Системный, English, 简体中文, Русский) и темы оформления (Системная, Тёмная, Светлая).

## Структура проекта

- `DisplaySessionManager`: отслеживание и выбор внешнего дисплея.
- `AppLauncher`: маршрутизация запуска и диагностика сбоев.
- `TouchpadActivity`: интерфейс тачпада и логика ввода.
- `RayMouseActivity`: управление курсором с помощью гироскопа телефона.
- `ControlAccessibilityService`: оверлей курсора, эмуляция пользовательских жестов, фокусировка внешнего окна и перенаправление кнопки «Назад».
- `CursorOverlayView`: отрисовка и анимация курсора.
- `DiagnosticsActivity`: статус и журнал последних событий/ошибок.

## Разрешения и примечания

- Использует `AccessibilityService` для эмуляции жестов, фокусировки внешнего окна, передачи «Назад» и аппаратных клавиш калибровки.
- Оверлей курсора использует `TYPE_ACCESSIBILITY_OVERLAY` без перехвата касаний.
- Оверлей привязывается к внешнему дисплею через `createWindowContext`.
- См. `docs/google-play-release.md` для контрольного списка деклараций Play Console.

## Ограничения

- Только Android 11+.
- Требуется поддержка вторичных дисплеев на уровне прошивки устройства.
- Некоторые сторонние приложения могут запрещать запуск на внешних экранах.
